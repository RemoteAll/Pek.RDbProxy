# Pek.RDbProxy · 项目记忆（仓库镜像）

> 本文件随 git 版本化，供**换电脑/新会话接续**使用。
> 同步方式（项目根目录运行）：`powershell -NoProfile -ExecutionPolicy Bypass -File tools\continuity\sync-memory.ps1`
>
> **新电脑首次**：先运行 `sync-memory.ps1 -Pull`（把本镜像并入本机记忆）再回灌，防止稀疏的本机记忆覆盖完整镜像。

## 项目定位

数据库**调试代理**（crate `pek-rdbproxy`，v0.1.0）：把真实数据库凭据收敛在一台机器，让**没有数据库账号的项目**能安全地调试数据层。

- 项目侧连接串：`Server=http://<proxy>:5599;Database=<Name>;Password=<Token>;provider=network`
- 协议：复用 Pek.RCode `provider=network`（`DbClient`）；`/Db/*` 成功返回**裸** `{data:…}` / `{DbType,Version}` / 数组，失败 `{code,msg}`
- 默认监听 `127.0.0.1:5599`，`AllowRemote=false` 时拒绝非回环

## 驱动组件（按需下载，2026-10-28）

- 内置：SQLite（`rusqlite` 恒内置）+ `Cargo.toml` 里的 `driver-mysql` / `driver-postgresql` / `driver-sqlserver`。
- 其余类型（Oracle / 达梦 / MongoDB / HANA / Firebird / ODBC / ClickHouse…）运行时从组件源下载 `dbserver-<类型>` 驱动包，解压到 `Data/Drivers/<组件>/<版本>/`，拉起宿主进程转 `provider=network`。
- 配置 `Config/Proxy.toml` 的 `[DriverStore]`：`Url`（空=默认 `https://p.sc8.fun`；`off`=仅本机缓存）、`PubKey`、`CaFile`、`ComponentFirst`（默认 false）、`CacheDir`（空=`Data/Drivers`）。
- 取驱动顺序：**本机组件缓存 → 内置驱动 → 联网下载**；打开数据源用 `DriverManager::ensure`（缓存优先，不每次联网）。
- 面板「设置 → 驱动组件」可看清单/安装/升级；接口 `GET /api/drivers`、`POST /api/drivers/install`、`POST /api/drivers/config`（保存后重建管理器并重开全部数据源）。
- `-status` 会多一行「驱动组件：组件源/内置/组件优先/缓存」。
- 模块：`src/drivers.rs`（`init` / `prepare` / `report` / `install` / `cache_dir` / `store` / `BUILTIN_PROVIDERS`）。

## 桌面工具（Tauri 2，2026-10-28）

- 定位：**真实消费方**——走 `pek_rcode::db_service::DbClient`，与项目侧 `provider=network` 同一条代码路径；跑通即说明代理可用。
- 三块能力：连接测试（Login→DbType/Version）、SQL 控制台（查询/执行/表结构/记录数）、协议自检（✔/✘/○ + 耗时 + 可操作原因）。
- 根 `Cargo.toml` 必须有 `[workspace] exclude = ["desktop"]`，否则嵌套 crate 报 workspace 归属错误。
- `DbClient` 同步阻塞 → Tauri 命令一律 `async fn` + `spawn_blocking`。
- 出站 UA 固定 `pek-rdbproxy-tool/<版本>`（WAF `block_empty_ua` 场景）。
- 常用命令（`desktop/` 下）：`cargo test -p pek-rdbproxy-tool-core`、`cargo run --example probe -- "<连接串>"`、`cargo run -p pek-rdbproxy-tool`。
- 构建默认落在项目内（代理 `target/`、工具 `desktop/target/`）；**不要**把 `CARGO_TARGET_DIR` 写进配置。只有磁盘真的不够时才临时 `$env:CARGO_TARGET_DIR=...`。中断编译后先清孤儿 `rustc` 进程再重编。

## 桌面工具 · 工作区（2026-10-28）

- 落盘：`%APPDATA%\com.peikesmart.rdbproxytool\{workspace.json,.key}`；令牌 AES-256-GCM 加密，**不下发前端**（前端只传连接 id）。
- `core/src/store.rs`：连接（按项目分组 + 健康状态）/ SQL 片段（命名+备注+绑定连接+使用次数）/ 历史（同连接同 SQL 去重，上限 200）/ 导入导出（导出含明文令牌）。
- 前端：左栏工作区 + 右栏执行区；单击选中、双击即连/即跑；`Ctrl+Enter` 查询、`Ctrl+Shift+Enter` 执行写；每连接一份 SQL 草稿。
- 开发用示例数据：`cargo run --example ws_seed -- "%APPDATA%\com.peikesmart.rdbproxytool"`（只写「示例」条目）。

## 双击即用（2026-10-28）
- **无参数启动**（双击 / 直接执行）时，`Config/Proxy.toml` 不存在会**自动写出模板并继续启动**，
  控制台打印「首次运行：已生成配置模板…」+ 面板地址 + 「关闭窗口=停止代理」。
- **服务 / `-run` / `-s` 不自动生成**（保持「配置就绪才运行」守卫，避免占位配置被反复拉起）。
- 排查坑：测试「空目录双击」前要清 `$env:PEK_RDBPROXY_BASE`（否则跑在旧基目录）；
  验证产物前要清 `$env:CARGO_TARGET_DIR` 并看 exe 时间戳（否则 cargo 把 exe 写到别处）。

## 审计字段（2026-10-28）

- `/api/audit` 每条含 `sql`（始终有，摘要 ≤300 字）/ `note`（**成功时**的备注，如字段策略拦截）/ `error`（**仅失败**）。
- `record(..., message)` 按 `ok` 分流：成功 → `note`，失败 → `error`；面板「SQL（备注 / 错误）」分行显示，SQL 不会被备注顶掉。
- 行数 `-1` 表示未知（Query 不数行），面板显示 `—`。

## 关键事实 / 坑

- **`/Db` 必须进 WAF 白名单**（`skip_attack_prefixes` + `set_forced_skip_bot_prefixes`）：SQL 文本会命中注入特征，DbClient 无浏览器 UA。
- **配置写回要 `merge_missing_keys`**：`apply_type_fixes` 只改已存在键，新字段不会落盘（否则每次启动重新初始化账号、JWT 密钥每次变）。
- **`Jwt::from_secret` 需 `算法:密钥`**（`HS256:hex`）→ `normalize_jwt_secret`。
- **SQLite 相对路径**用 `pek_rcode::database::resolve_connection(base, &raw)` 解析成绝对路径。
- 面板账号首次启动自动初始化为 `admin/admin`（`WebPasswordHash` 为空时），面板显横幅提示改密。
- 构建前若程序在跑，先 `Get-Process pek-rdbproxy | Stop-Process -Force`（否则 exe 被占用）。
- rsproxy 拉不到新版 `cc` 时：复制 `Pek.RCode/Cargo.lock` + `--offline`。
